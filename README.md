# Silkways Cargo Portal

## Run
```
npm install
npm run dev
```

## Where to edit
- Text: `src/config/content.js`
- Colors / font: `@theme` block in `src/index.css`
- Button + background styles: `@layer components` in `src/index.css`
- Logo: paste your SVG in `src/assets/Logo.jsx`
  (or save it as `src/assets/logo.svg` and use `<img src={logo} />`)
- Circle icon (robot spot): `PlaneIcon` in `src/components/Hero.jsx`
